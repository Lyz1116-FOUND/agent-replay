# Harness task fixtures

Ten self-contained Python tasks for the coding harness. Each directory has:

- `task.json` — id, instruction, test command, protected paths, expected paths.
- `src/` — the buggy or incomplete project (copied to the agent workspace).
- `tests/` — the acceptance suite; protected from edits.
- `pytest.ini` — test root and import path; protected from edits.
- `CONTEXT.md` — a long repository note used by context-strategy experiments.
- `reference/` — the reference fix. It is **excluded** from the agent workspace
  and used only by validation and scripted mechanics policies.

`task.json` uses `{python}` in the test command; the harness replaces it with
the interpreter running the harness, so no shell PATH setup is required.

```bash
python -m agent_replay.harness validate-tasks
```

`validate-tasks` copies each task into a temporary git workspace, proves the
baseline suite fails, applies `reference/`, and proves the suite passes.

The task set was generated by `scripts/gen_harness_tasks.py`. The script is
idempotent only for a fresh directory; edit it before regenerating the set.
